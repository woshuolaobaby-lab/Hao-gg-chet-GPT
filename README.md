# FundRadar V15 大盘优先版

独立的 Streamlit 大盘监测应用。保留白色风格，聚焦六大指数、多源公开报价、全市场股票宽度、成交额版TRIN、指数技术指标及数据源诊断。

## GitHub 部署
1. 先备份原仓库（原来的153只基金版）。
2. 将压缩包内 `app.py`、`requirements.txt`、`README.md` 上传覆盖仓库根目录同名文件。
3. 在 GitHub 新建或编辑 `.streamlit/config.toml`，粘贴压缩包中同名文件的内容。若已经有白色主题配置可不覆盖。
4. Commit changes；Streamlit Cloud 应用入口文件选择 `app.py`，等待重新部署。
5. 页面上先检查「数据通道诊断」；再打开全市场快照开关。

## 严谨限制
- 腾讯、新浪、东方财富均为非SLA公开网页接口；在 Streamlit 云端可能被阻断，不能保证实时可用。
- 股票宽度只有获取完整分页、且有效股票达到3000只时才计算；失败显示缺失，不生成假数。
- 成交额TRIN与标准成交量TRIN不同，页面明确标注。
- 历史指数日线目前依赖东方财富历史接口；失败时不生成技术指标。
- 未保留原基金153只明细，此包是用户要求的「不必考虑基金数据」独立大盘优先版本。
- 代码未经 Streamlit Cloud 实际联网测试；请在部署后查看数据源诊断。


## 完整包文件说明
- `app.py`：V15 大盘监测主程序。
- `requirements.txt`：V15 所需依赖。
- `relative_value.py`：旧版股债分析兼容文件，V15 主程序目前不调用；不代表V15已经集成股债性价比监测。
- `.streamlit/config.toml`：白色界面配置。
- `README.md`：使用说明。

注意：V15 当前是大盘数据通道验证版，沪深300股债性价比、长期历史数据持久化仍需后续集成。
